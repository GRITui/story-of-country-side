## Regeneration

Every `.png` in this directory is byte-derived from a deterministic script
under `assets/pixelart/generator/`. Re-running it reproduces the same set:

```
cd assets/pixelart/generator
python3 gen_tiles.py
python3 gen_characters.py
python3 gen_crops.py
python3 gen_animals.py
python3 gen_items.py
python3 gen_props.py
python3 gen_map.py
python3 gen_ui_icons.py
```

Requires Python 3.9+ and Pillow (`python3 -c "import PIL"` to check). No
network access is used — all color and geometry is authored in the scripts.
