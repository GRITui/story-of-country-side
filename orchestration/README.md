# Orchestration Loop Artifacts

Owned by the ox-alpha orchestration session (cross-functional AI team running the agile loop: assess -> plan -> build -> test -> complete sprint -> repeat).

Layout:
- assessments/ — per-version multi-persona play simulations (scripts/ holds the headless SceneTree drivers)
- sprints/    — per-sprint plans with scoped issues + acceptance criteria
- reports/    — per-sprint completion reports

Conventions: append-only mindset like the rest of this repo; never rewrite a shipped report; findings use the P0-P4 severity scale defined in SUPERUSER.md; lane ownership follows SQUAD-SPLIT.md.
